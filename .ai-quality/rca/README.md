# island-building RCA 病例庫

此目錄是正式且受 Git 管理的病例庫。以 [索引](index.md) 找案例，以 [範本](TEMPLATE.md) 建新案；專案根目錄的 `.ai-quality/rca/` 只是入口，不另維護一套結論。

## 接力前先做

1. 確認工作目錄、`git status`、目前 commit 與實際發布版本。正式 repo 為 `github/gsat-writing-class-island`；舊 Downloads 入口與 `writing-island` 不代表正式網站。
2. 讀索引及相關案例。用現象與技術關鍵字一起找，例如「閃屏／黑屏／重載／Safari／WebGL／解析度」。找不到單一詞不代表沒有歷史紀錄。
3. 分開記錄使用者回報、已觀測事實、推測、未驗證事項。過去對話與舊案例是線索，不能冒充本輪實測。
4. 開發前寫出受影響路徑與驗收；使用者先發現錯誤時，先補 RCA。緊急止血可先處理，再補分析。
5. 交接寫出版本、未解問題、證據位置與下一個可驗證步驟。未實作的討論方案不得寫成現況；症狀暫時消失不等於根因已修復。

## 狀態與證據

- **待復現**：有回報或線索，但尚未捕捉關鍵現象；原因可以保持未知。
- **已定位／修正中**：根因已有可定位證據，或修正進行中。
- **已修正待驗收**：有修正版本，但必要驗證未完成。
- **已驗證關閉**：修正與必要驗證都有證據，另註明真機等限制。
- 舊案例保留原文，不能只因索引寫「有效」就推定問題已關閉。
- `PASS` 只描述指定驗證。文件連結檢查通過，不等於事故已修復。

原始根因查不到就寫「未定因」。證據放在本庫 `evidence/<case>/` 或受版本管理的既有 `research/evidence/`；保留量測方法、時間、版本與限制。`/tmp`、截圖臨時路徑、對話網址只能作補充，不能是唯一交接證據。避免納入帳號、私人畫面、憑證與無關內容。

## 特別注意：Safari 黑屏與 WebGL

先讀 [目前待復現案例](CASE-20261117-safari-webgl-black-screen.md)。整頁重載、WebGL context 遺失／恢復、畫布重新配置是三種不同事件，需分開量測。沒有捕捉到某事件，不代表它從未發生。既有告示牌畫質鎖定已發布，不得當成未發布方案。已實作有界恢復與停止循環的緩解；Safari 成功恢復仍未驗證，不得宣稱原始根因已修復或保證完全不閃。

## 新案與交接

檔名使用 `CASE-YYYYMMDD-<slug>.md`，日期以 Asia/Taipei 為準。新案建立後必須加入索引，寫入會被下一位協作者讀到的規則入口；必要時更新專案 AGENTS.md。不要為同一事故在不同資料夾各寫一套結論，也不要覆蓋原始證據。

根目錄入口與本 repo 規範都會導向本庫；只能保證入口存在，不能保證所有外部工具會自動載入。接力者仍須實際讀取。
