# 孟婆島

「孟婆茶會」的互動 3D 介紹島：https://khlin712.github.io/mengpo-party/

五座島加兩座橋 = 七個認識孟婆茶會的入口（崎嶇島、疑問橋、茶會、奈何橋、繽紛世界、場次、LINE 報名）。參加活動，就能以「上帝視角」看見自己卡住的人生問題，打開迷霧、跳出迴圈。

## 設計來源

機制參考 [HEART 政策島](https://puma.taipei/heart-island) 的互動設計（以 [REA](https://github.com/morluto/rea) 與直接閱讀前端程式拆解）：一格一座島、島與島之間用線表示關係、一天的時間軸、自動導覽、可搜尋的清單。**程式、造型與文案全部重寫，沒有複製對方的程式碼或素材。**

| 機制 | 孟婆島的做法 |
| --- | --- |
| 六角格拼成的城市 | 5 座六角島＋2 座橋，依旅程順序排成一直線的步驟（編號＝順序）：崎嶇島 →【疑問橋】→ 茶會 →【奈何橋】→ 繽紛世界 → 嘗試（場次）→ 報名。橋也是內容：**疑問橋**（人們心中的疑問，歪斜的暗色橋、紫色燈籠與飄浮的問號）、**奈何橋**（說明工作怎麼進行，紅色拱橋、植物光點、橋下蓮花），點橋看內容 |
| （新增）島上的人物 | 導覽員與參加者沿路徑走完整趟（過橋後衣服由灰變彩色）、各島有示意角色；點人物看台詞，點導覽員開始導覽。台詞只取自本站已有的問題與介紹，卡片標明是示意人物 |
| 一格政見＝一座島，島上有細項 | 一座島／橋＝一個主題，島上的小屋、橋邊的路牌＝重點，點開看細節 |
| 協作線 | 已從介面移除（對訪客沒有實際用途）；資料仍保留在 `content.js` |
| 台北人的一天 | 島上的一天：時間滑桿控制天空、太陽／月亮、燈籠、火山口、星星與彩虹（只在「探索」模式出現）。預設為黃昏 18:30；水面是「忘川河」，水流垂直於路線、從橋下穿過，水色由疑問橋下的暗紫、茶會的茶色，到繽紛世界的清澈青色，漂著河燈 |
| 任期時間軸 | 「走一圈」：依旅程七站走訪 |
| HEART 分類篩選 | 主題分類複選，其餘的島淡化 |
| 搜尋與清單、卡片 | 左側清單＋搜尋，右側詳細卡；手機變成底部抽屜 |
| 78 秒導覽 | 72 秒自動導覽（鏡頭、時間、關聯線、字幕同步） |
| 「你是台北的哪一種人」測驗 | 「你最在意哪一種問題」：愛情／夫妻、親子、迷茫，排出參觀順序 |
| （新增）首頁與文字版 | 進站先看白話說明（適合誰、現場做什麼、怎麼進行）、場次與報名入口、常見疑問與完整文字版；地圖是第二條路徑。`/#text` 直接開文字版 |
| （新增）報名／場次 | 工具列固定有「報名／場次」按鈕，隨時打開場次、費用與 LINE 報名 |
| （新增）探索模式 | 時間、人物、名牌、鳥瞰、導覽等次要控制，收進工具列的「探索」 |
| （新增）我的提綱 | 收藏想聊的島、寫下情況，複製後貼到 LINE；只存在瀏覽器 |

分享連結：`/#teaching`、`/#questions/2`（島 / 第幾個重點）。`/?tour=1` 直接開始導覽。

## 本機預覽與測試

```sh
npm start   # http://127.0.0.1:4173/  （Python 3）
npm test    # Node.js，不需安裝套件
```

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `dist/content.js` | 7 座島、關聯線、導覽、入口路線、顧慮 Q&A |
| `dist/journey.js` | **老師填寫**：LINE 連結、場次、客戶回饋、價格、影片 |
| `dist/world.js` | three.js 場景：島、橋、海、天空、迷霧、弧線 |
| `dist/people.js` | 人物造型、走路路徑與各島角色（台詞在 `content.js` 的 `PEOPLE`） |
| `dist/app.js` | 介面與互動：選取、鏡頭、清單、導覽、提綱 |
| `dist/lib.js` | 與 three.js 無關的純計算（六角格座標、天空色彩、曲線） |
| `dist/motion.js`、`dist/resolution.js` | 鏡頭緩動、依畫面流暢度調整畫質 |

## 還需要老師提供（目前一律顯示「待老師提供」，不虛構）

- LINE 官方帳號網址：`dist/journey.js` 的 `CONTACTS`（報名島的按鈕會自動啟用）
- 近期場次、價格確認：`CLASSES`、`PRICING`
- 客戶回饋（需本人同意，`consent: true` 才會顯示）：`FEEDBACK`
- 前、中、後案例、活動照片
- 待確認用語：列穆里亞、「植物花與星際」的共振頻率、累計人數與場次

## 發布

`main` 存完整原始碼，`gh-pages` 存 `dist/` 的內容；所有資源使用相對路徑。

```sh
npm test
git push origin main
git subtree push --prefix dist origin gh-pages
```

Three.js 0.180.0 與附屬模組隨站提供，MIT 授權見 `dist/vendor/LICENSE`。訪客的筆記與問題只存在瀏覽器，不會代發訊息，網站沒有任何追蹤程式。
